# moncef

Design project.

## Getting started

```bash
# clone
git clone git@github.com:D-upe/moncef.git
cd moncef

# install (when a Node project is added)
npm install
```

## Workflow

- `main` is always deployable
- Work in short-lived branches: `feature/<name>`, `fix/<name>`
- Commit early, commit often with conventional messages (`feat:`, `fix:`, `chore:` …)
